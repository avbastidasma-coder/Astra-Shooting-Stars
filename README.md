# Astra Shooting Stars

Astra Shooting Stars is a 2D shooting game developed as an academic project for the course Creación de Entornos y Personajes at UNAD.

## Project Description

The game takes place in the magical universe of Astralis, where Astra Luminara must destroy enchanted stars using cosmic energy projectiles.

## Project Structure

- Sprites
- Environment Assets
- User Interface
- Unity Integration
- Pitch Presentation
- Video Demonstration
